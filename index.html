TASTE scorer test demo

TASTE is a pairwise preference scorer. This demo uses battles_test.csv and shows both raw pairwise probabilities and per-image scores aggregated from those pairwise model outputs.

Per-image score = mean P(candidate wins) against the other candidates for the same prompt. The model itself is still pairwise, so the table is an aggregation of raw A-vs-B outputs rather than an independent single-image forward pass.
